# 대한노인낙상예방협회(KAEFP) 홈페이지 시안

빌드 과정 없는 정적 사이트입니다. `index.html`을 브라우저로 열거나 아무 정적 호스팅(웹 서버, GitHub Pages 등)에 그대로 올리면 됩니다.

- 7개 대메뉴 + 메가메뉴(데스크톱) / 전체메뉴 드로어(모바일)
- 페이지는 `#토큰` 해시 라우팅 (예: `#about-greeting`, `#biz-local`, `#selfcheck`)
- 글자 크기 3단계, 라이트/다크 모드 대응
- 신청 폼은 시안이며 데이터를 저장·전송하지 않습니다. 회원 기능은 개인정보처리방침 게시, 위탁계약, 보호책임자 지정 후 서버와 함께 엽니다.
- 공지·게시판·자료실·지도자 명단의 행은 모두 "예시" 데이터입니다 (`index.html` 스크립트 상단의 `NOTICES`, `BOARDS`, `LIB`, `LEADERS`).
